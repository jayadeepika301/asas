# Asas - React Component Suite ⚡

A high-performance, interactive React component suite built with modern React, Vite, and glassmorphism styling, automatically deployed to Vercel.

## ✨ Features

- **Component Control Center**: Interactive state management, event hooks, and reactive milestone tracking with real-time feedback.
- **Dynamic KPI Sparklines**: Interactive timeframe switcher (Day, Week, Month, Year) with vector SVG trend lines and growth badges.
- **Props Explorer & Code Playground**: Live prop editing with instantaneous React snippet generation.
- **Dark / Light Theme System**: Zero-lag theme toggling with CSS design tokens and backdrop filters.
- **Confetti Micro-interactions**: Smooth celebratory particle physics on milestone completions.
- **Zero Config Build**: Fully optimized Vite pipeline with fast HMR.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/jayadeepika301/asas.git

# Navigate to project directory
cd asas

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Build for Production

```bash
npm run build
```

## 🌐 Deployment

Deployed seamlessly on [Vercel](https://vercel.com).
